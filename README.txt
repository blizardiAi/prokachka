ПРОКАЧКА ПРИВЫЧЕК — отдельная версия
Один и тот же набор файлов работает как сайт (с установкой на экран «Домой»),
как мини-приложение Telegram и как мини-приложение VK.

ЧТО В ПАПКЕ
  index.html              всё приложение целиком
  manifest.webmanifest    название и иконки для установки на главный экран
  sw.js                   работа без интернета (только в режиме сайта)
  icon-*.png, favicon.svg иконки
Все файлы должны лежать рядом, в одной папке на хостинге. Нужен адрес с https.

ШАГ 1. ХОСТИНГ
Бесплатный тариф Тильды не подойдёт: на нём отключён блок с HTML-кодом (T123)
и вставка кода в head, а без них приложение не запустить.
Бесплатный вариант, где это работает, — GitHub Pages:
  1. Зарегистрируйся на github.com.
  2. New repository → имя, например prokachka → Public → Create.
  3. Add file → Upload files → перетащи все файлы из этой папки → Commit changes.
  4. Settings → Pages → Source: Deploy from a branch → Branch: main, папка / (root) → Save.
  5. Через минуту-две приложение откроется по адресу
     https://ТВОЙ_ЛОГИН.github.io/prokachka/
Этот адрес дальше используется во всех трёх вариантах.

ШАГ 2А. АЙФОН: ИКОНКА НА ЭКРАНЕ «ДОМОЙ»
  1. Открой адрес в Safari.
  2. Нажми «Поделиться» (квадрат со стрелкой вверх) → «На экран „Домой“» → «Добавить».
  3. Запускай с иконки: приложение откроется на весь экран, без строки браузера.
Важно: у установленного приложения своя память, отдельная от Safari. Заполняй журнал
уже после установки. Перенести старые записи можно так: Журнал → Хранилище →
«Сохранить копию в файл», потом в установленном приложении «Восстановить из файла».
На Android то же самое делает кнопка «Установить» в подсказке Chrome.

ШАГ 2Б. TELEGRAM
  1. Напиши @BotFather → /newbot → задай имя и логин бота.
  2. /mybots → выбери бота → Bot Settings → Configure Mini App → Enable Mini App →
     вставь адрес из шага 1. Приложение откроется кнопкой в профиле бота.
  3. По желанию: Bot Settings → Menu Button → тот же адрес. Тогда кнопка будет
     и в чате с ботом.
  4. Прямая ссылка, которой можно делиться: https://t.me/ЛОГИН_БОТА?startapp
В Telegram журнал дополнительно сохраняется в облаке Telegram и подтягивается
на другом телефоне под тем же аккаунтом. Тема (светлая/тёмная) берётся из Telegram.

ШАГ 2В. VK
  1. Открой vk.com/apps?act=manage → «Создать» → тип «Мини-приложение».
  2. В настройках приложения укажи адрес из шага 1 для мобильной версии,
     m.vk.com и vk.com и включи приложение.
  3. Пока приложение не прошло модерацию, оно открывается по прямой ссылке
     vk.com/appНОМЕР тебе и тем, кого ты добавил в тестировщики. Чтобы попасть
     в каталог, его нужно отправить на модерацию там же, в настройках.
Названия пунктов в кабинете VK могут немного отличаться: я сверял их по памяти,
документация VK в момент сборки была недоступна.
В VK журнал дополнительно сохраняется в хранилище VK для твоего аккаунта.

ЧТО ГДЕ ХРАНИТСЯ
  Сайт / иконка на айфоне   только память устройства + копия в файл вручную
  Telegram                  память устройства + облако Telegram
  VK                        память устройства + хранилище VK
Память устройства браузер может очистить (например, если долго не открывать сайт
в Safari или удалить иконку). Раз в неделю-две сохраняй копию в файл.

ЧЕГО ЗДЕСЬ НЕТ
  Разбор от ИИ работает только внутри Claude: ему нужен аккаунт Claude.
  В отдельной версии остаётся сводка по правилам (вкладка «Навыки» → «Разбор»).
  Чтобы вернуть ИИ, понадобится свой сервер и платный ключ API.

КАК ОБНОВИТЬ
  Загрузи новый index.html поверх старого и поменяй в sw.js строку
  VERSION="pp-v1" на "pp-v2" (и так далее), иначе телефон какое-то время
  будет показывать старую версию из памяти.
